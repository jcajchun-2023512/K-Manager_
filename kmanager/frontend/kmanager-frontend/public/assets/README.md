# Assets del Login

Colocá acá estos dos archivos (los nombres deben coincidir exactamente):

- `logo-kmanager.png`  -> Logo que se muestra en el header del login.
- `hero-kmanager.jpg`  -> Imagen de fondo del panel derecho (hero).

Si no los agregás, el sitio sigue funcionando: el logo cae automáticamente
al texto "K-Manager" y el hero muestra un degradado verde/slate en vez de foto.

Las URLs originales de code.html (lh3.googleusercontent.com/aida-public/...)
son enlaces temporales generados por una herramienta de diseño (Google AI
Studio) y no son confiables para producción: pueden expirar o dar 404 en
cualquier momento. Por eso el proyecto ya no las referencia directamente.
